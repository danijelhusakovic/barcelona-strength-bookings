# Barcelona Strength Bookings

Personal training booking platform for Alex Moreno, strength coach based in Barcelona.

Built with [TanStack Start](https://tanstack.com/start) + React 19, deployed on Vercel.

## Stack

- **Framework**: TanStack Start (file-based SSR routes)
- **Styling**: Tailwind CSS v4
- **UI**: Radix UI primitives + shadcn/ui components
- **Data**: TanStack Query
- **Forms**: React Hook Form + Zod
- **Analytics**: Vercel Analytics

## Development

```bash
npm install
npm run dev
```

## Deployment

Deploys automatically to Vercel on push to `main`. SSR via Nitro.
